# Human Digital Baseline v0.1

Static PWA research prototype.

## Deploy on Vercel
1. Create a GitHub repository.
2. Upload `index.html` and `manifest.json` to the repository root.
3. In Vercel choose **Add New → Project** and import the repository.
4. Framework preset: **Other**. No build command is needed.
5. Deploy.

The app runs entirely client-side in this version. It does not upload data to a server.

IMPORTANT: This is a technical prototype, not a medical device. Do not collect research data from participants until an appropriate research protocol, consent/privacy process, and supervision are in place.
